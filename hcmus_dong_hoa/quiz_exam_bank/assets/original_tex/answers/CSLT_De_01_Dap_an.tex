\section*{Đáp án và lời giải - Đề 01}
\begin{enumerate}
\item \begin{minipage}[t]{\linewidth}
Ban đầu $a=2,b=4,s=0$. Biểu thức \texttt{a++ < 3} dùng giá trị cũ $2$ nên đúng, sau đó $a=3$. Vì vế trái đúng, xét tiếp \texttt{++b == 5}: $b$ tăng lên 5 và điều kiện đúng. Do đó $s=5$. Vòng \texttt{for} cộng $1+2+3=6$, suy ra $s=11$. Kết quả: \texttt{3 5 11}.
\end{minipage}
\item \begin{minipage}[t]{\linewidth}
Mã C++11 tham khảo:
\begin{lstlisting}
int sumMultiples(int n, int k = 3) {
    int sum = 0;
    for (int i = k; i <= n; i += k)
        sum += i;
    return sum;
}
\end{lstlisting}
Ví dụ \texttt{sumMultiples(10)} trả về $3+6+9=18$; \texttt{sumMultiples(10,2)} trả về 30. Tham số có giá trị mặc định phải nằm sau các tham số không có mặc định.
\end{minipage}
\item \begin{minipage}[t]{\linewidth}
\texttt{x} nhận bản sao của $a$, nên việc tăng \texttt{x} không làm đổi $a$. Sau \texttt{x += 3}, $x=5$; \texttt{y} là bí danh của $b$, nên \texttt{y += x} làm $b=10$. Kết quả: \texttt{2 10}.
\end{minipage}
\item \begin{minipage}[t]{\linewidth}
Mã C++11 tham khảo:
\begin{lstlisting}
long long sumPositive(const int a[], int n, int &cnt) {
    long long sum = 0;
    cnt = 0;
    for (int i = 0; i < n; ++i) {
        if (a[i] > 0) {
            sum += a[i];
            ++cnt;
        }
    }
    return sum;
}
\end{lstlisting}
Vòng lặp không chạy khi $n=0$, nên kết quả tự nhiên là tổng 0 và \texttt{cnt}=0.
\end{minipage}
\item \begin{minipage}[t]{\linewidth}
Mã C++11 tham khảo:
\begin{lstlisting}
int rowWithMaxSum(const int a[][MAX], int R, int C) {
    int bestRow = 0;
    long long bestSum = 0;
    for (int j = 0; j < C; ++j) bestSum += a[0][j];

    for (int i = 1; i < R; ++i) {
        long long sum = 0;
        for (int j = 0; j < C; ++j) sum += a[i][j];
        if (sum > bestSum) {
            bestSum = sum;
            bestRow = i;
        }
    }
    return bestRow;
}
\end{lstlisting}
Chỉ cập nhật khi tổng lớn hơn, không cập nhật khi bằng nhau, nên tự động giữ hàng xuất hiện trước.
\end{minipage}
\end{enumerate}
