\section*{Đáp án và lời giải - Đề 05}
\begin{enumerate}
\item \begin{minipage}[t]{\linewidth}
Mã C++11 tham khảo:
\begin{lstlisting}
int reverseDigits(int n) {
    int result = 0;
    while (n > 0) {
        int digit = n % 10;
        result = result * 10 + digit;
        n /= 10;
    }
    return result;
}
\end{lstlisting}
Với $n=2048$: lần lượt lấy chữ số 8, 4, 0, 2 và ghép vào kết quả, thu được 8402. Với $n=0$, hàm trả về 0.
\end{minipage}
\item \begin{minipage}[t]{\linewidth}
Mã C++11 tham khảo:
\begin{lstlisting}
long long factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
\end{lstlisting}
Điều kiện dừng là $n=0$ hoặc $n=1$, vì $0!=1!=1$. Ví dụ $4!=4\cdot3\cdot2\cdot1=24$.
\end{minipage}
\item \begin{minipage}[t]{\linewidth}
Mã C++11 tham khảo:
\begin{lstlisting}
void findMinMax(const int a[], int n, int &mn, int &mx) {
    mn = mx = a[0];
    for (int i = 1; i < n; ++i) {
        if (a[i] < mn) mn = a[i];
        if (a[i] > mx) mx = a[i];
    }
}
\end{lstlisting}
Khởi tạo bằng phần tử đầu tiên giúp xử lý đúng cả mảng toàn số âm; không nên khởi tạo min/max bằng 0.
\end{minipage}
\item \begin{minipage}[t]{\linewidth}
Mã C++11 tham khảo:
\begin{lstlisting}
bool insertAt(int a[], int &n, int capacity, int pos, int x) {
    if (n >= capacity || pos < 0 || pos > n) return false;
    for (int i = n; i > pos; --i)
        a[i] = a[i-1];
    a[pos] = x;
    ++n;
    return true;
}
\end{lstlisting}
Dịch từ phải sang trái để không ghi đè phần tử chưa được chuyển. Chỉ tăng $n$ sau khi chèn thành công.
\end{minipage}
\item \begin{minipage}[t]{\linewidth}
Mã C++11 tham khảo:
\begin{lstlisting}
int countNonNegativeColumns(const int a[][MAX], int R, int C) {
    int answer = 0;
    for (int j = 0; j < C; ++j) {
        bool ok = true;
        for (int i = 0; i < R; ++i) {
            if (a[i][j] < 0) {
                ok = false;
                break;
            }
        }
        if (ok) ++answer;
    }
    return answer;
}
\end{lstlisting}
Duyệt từng cột; chỉ cần gặp một phần tử âm là có thể dừng kiểm tra cột đó.
\end{minipage}
\end{enumerate}
