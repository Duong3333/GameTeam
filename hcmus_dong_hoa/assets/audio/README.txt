Bỏ file âm thanh vào thư mục này (.ogg, .wav hoặc .mp3).
Gọi trong code bằng TÊN FILE, không cần đuôi:
  audio.play_sfx("click")   -> assets/audio/click.ogg
  audio.play_music("nen")   -> assets/audio/nen.ogg
Thiếu file thì game vẫn chạy, chỉ là không có tiếng.

Âm thanh câu cá (tùy chọn, tên file không cần đuôi): rod (lấy cần), cast (quăng), splash (phao chạm nước),
bite (cá cắn câu), reel (bắt đầu kéo cá), catch (bắt được), fail (cá sổng).
